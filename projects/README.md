# Projects

This directory contains complete, production-style projects that combine multiple AWS services.

Unlike the labs, these projects simulate real-world deployments.

Planned projects include:

1. Static Website Hosting
2. Three-Tier Web Application
3. Containerized Application Deployment
4. Monitoring & Observability Stack
5. CI/CD Pipeline
6. Infrastructure as Code with Terraform

Each project includes:

- Architecture diagram
- Terraform code
- Deployment guide
- Troubleshooting
- Lessons learned
