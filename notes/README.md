# Notes

This directory contains my personal AWS study notes.

Each AWS service has its own Markdown document following a consistent structure:

- What problem does it solve?
- What is it?
- Real-world analogy
- When should I use it?
- When should I avoid it?
- Pricing model
- Security considerations
- AWS CLI examples
- Terraform examples
- Interview questions
- Common mistakes
- Production tips
- Personal observations

These notes are written in my own words to reinforce understanding rather than copy documentation.
